## 📌 Projects

### 🎬 MiniMovie — Full-Stack Film Discovery Platform

A full-stack film discovery and personal film journal application focused on curated cinema recommendations.

**Live Demo:**  
https://mini-movie-phi.vercel.app

**GitHub:**  
https://github.com/Shouldgooo/mini-movie

**Tech Stack:**  
Next.js · React · TypeScript · Express · PostgreSQL · Prisma · Docker

**Features:**
- Curated film discovery and Daily Film recommendations
- Film collections and bilingual English / Chinese interface
- User registration and JWT authentication
- Favourite films and personal reviews
- Personal film journal with persistent PostgreSQL data
- TMDB API integration through the backend
- Automated testing with Vitest and Supertest
- CI with GitHub Actions
- Automatic deployment through Vercel and Render

**Production Architecture:**

`Vercel (Next.js) → Render (Express API) → Supabase (PostgreSQL)`
